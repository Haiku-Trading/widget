# Changelog

All notable changes to the Haiku Swap Widget will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [Unreleased]

### Added
- Initial release of Haiku Swap Widget
- Core swap functionality with input/output token selection
- Multi-chain support (Ethereum, Polygon, Berachain, and more)
- Customizable theming system
- Multiple display modes (compact, full, drawer)
- Wallet integration with popular Web3 wallets
- Real-time quote updates
- Comprehensive error handling
- TypeScript support with full type definitions
- Responsive design for mobile and desktop
- Custom CSS injection support
- Slippage tolerance configuration
- Default token presets
- Chain restriction capabilities

### Technical Features
- React 18+ compatibility
- Wagmi v2 integration
- Rollup build system with tree-shaking
- ESM and CommonJS module support
- Source maps and declaration files
- Peer dependency management
- Comprehensive ESLint configuration

## [0.1.0] - 2024-12-19

### Added
- Initial beta release
- Basic swap functionality
- Token selection interface
- Wallet connection handling
- Mock swap execution for testing

### Known Issues
- Mock quote generation (to be replaced with real API integration)
- Limited token list (to be expanded with real token data)
- Basic error handling (to be enhanced with real error scenarios)
