Haiku Swap Widget Demo

A standalone, embeddable trading interface widget

Widget Preview

This is where the HaikuSwapWidget component would be rendered.

In a real implementation, you would see the full trading interface here.

// Basic usage
import { HaikuSwapWidget } from '@haiku/swap-widget';

function App() {
  return (
    <HaikuSwapWidget 
      apiKey="your-api-key-here"
      theme="light"
      defaultChainId={1}
    />
  );
}

🚀 Easy Integration

Drop the widget into any React application with just a few lines of code.

🔌 Wallet Support

Built-in support for MetaMask, WalletConnect, and other popular wallets.

🌐 Multi-Chain

Support for Ethereum, Polygon, Arbitrum, Optimism, Base, and more.

🎨 Customizable

Customize themes, colors, and supported chains to match your brand.

// Advanced configuration
<HaikuSwapWidget 
  apiKey="your-api-key"
  baseUrl="https://custom-api.haiku.trade/v1"
  theme="dark"
  defaultChainId={137}
  supportedChains={[1, 137, 42161]}
  customStyles={{
    primaryColor: '#3B82F6',
    borderRadius: '12px',
    fontFamily: 'Inter, sans-serif'
  }}
/>
